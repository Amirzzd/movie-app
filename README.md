# Movie App

A Flutter-based movie app that allows users to browse and explore movie details using data from [The Movie Database API](https://api.themoviedb.org). The app is built with feature-driven architecture and uses BLoC for state management. Authentication is required to access certain features of the app, but you need to set up your own authentication server for this functionality.

## Features
- **Movie Browsing**: View popular movies, details, and ratings.
- **Search**: Search for movies by name or genre.
- **Authentication**: Login and register users (requires your own authentication server).
- **State Management**: Uses the BLoC (Business Logic Component) pattern to manage the app’s state.
- **API Integration**: Fetches data from The Movie Database API.

## Architecture
- **Feature-driven Architecture**: The project is organized into distinct features that handle specific aspects of the app (e.g., movie listing, authentication).
- **BLoC for State Management**: Implements BLoC to manage state changes in a scalable way and separate business logic from the UI layer.

## Prerequisites

- Flutter SDK
- Dart SDK
- Your own Authentication server (for handling login/registration)
